## 使用建议

1. 想知道**现在为什么这样设计** → 先查 42 号（架构现状）与相关 ADR；
2. 想知道**某功能的验收标准与测试证据** → 找对应批次的"测试报告/验收报告"；
3. 想知道**某个坑的根因分析** → 42 号 O1–O7 与各审查裁定文档；
4. 34 章本身不维护详情——新增设计请继续放 `docs/下一阶段/`（按编号递增）或 `docs/adr/`。
