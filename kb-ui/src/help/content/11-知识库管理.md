# 11 · 知识库管理

页面：`/kb`（库列表）、新建库弹窗、库详情「设置」tab｜所有人可用

## 知识库是什么

保存有权限的原始资料、来源、版本和加工视图的"仓库"（见第 02 章）。每个库有：

- **名称**（如"5G 规范库"）与**描述**；
- **可见性**：私有（默认，仅拥有者和成员）或**公开读**（本域全员可读）；
- **归属域**：库归属创建者所在域；
- **库内角色**：拥有者 / 编辑者 / 只读（见第 02 章词典）。

## 库列表页

- 列出**你可见的**库：你拥有的、你是成员的、公开库；
- 每行显示库名、文档数等概要，点击进入库详情页；
- 已删除的库折叠在「已删除的知识库」分组中——**该分组仅站点管理员/域管理员可见**（普通拥有者删除库后自己看不到）。

### 新建知识库

点「新建」打开弹窗，四个字段：

| 字段 | 说明 |
|---|---|
| 名称 | 必填，如"5G 规范库" |
| 域 | **自动取本人所属域，不可修改** |
| 描述 | 可选，"简要描述这个知识库的用途" |
| 公开读 | 勾选后本域全员可读 |

### 已删除库的操作

对已删除的库可以：**恢复**（回到列表）、**彻底删除**（不可恢复）。

## 库详情「设置」tab

| 操作 | 说明 |
|---|---|
| **转移所有者** | 把库转给别人（候选搜索选择新拥有者）；当前拥有者仍拥有知识库时，移除操作会被后端拒绝——先转移 |
| **永久删除知识库** | 全名确认后硬删，**不可恢复**（连带全部文档与挖掘内容，走统一删除管线） |

## 谁能对库做什么

| 操作 | 需要什么权限 |
|---|---|
| 浏览、检索库内容 | 拥有者 / 库成员 / 库是 public，三选一 |
| 上传、修改文件、发起挖掘 | 拥有者或编辑者 |
| 管理成员 | 拥有者或编辑者（页面提示："仅拥有者或编辑者可管理成员"） |
| 修改挖掘范式绑定 | 拥有者或编辑者 |
| 转移拥有者 / 删除库 | 拥有者 |

公开库全员可读，无需添加只读成员——成员入口仅用于授予「编辑者」写权限。

> 已知边界：别人建的**私有库**，即使你是站点管理员，直接检索也会 404（检索侧授权没有管理员旁路）。规避：让拥有者把你加为成员、把库设为 public、或用拥有者身份。

## 库详情页的七个页签

| 页签 | 内容 | 详见 |
|---|---|---|
| 文件 | 上传、文件管理、挖掘触发（含文档预览页入口） | 第 12 章 |
| 检索 | 网页检索 | 第 14 章 |
| 成员 | 库内角色管理 | 第 20 章 |
| 挖掘 | 范式绑定、挖掘发起与记录 | 第 13 章 |
| 质量 | 结构完整度/表格完整度/来源定位覆盖等质量报告 | 第 13 章末 |
| 一张网 | 本库引用的一张网文档 | 第 16 章 |
| 设置 | 转移拥有者、永久删除 | 本章上文 |
