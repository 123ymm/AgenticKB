# 16 · 一张网接入

页面：`/onenet`（管理员导入）、库详情 ·「一张网」tab（引用侧）｜导入仅站点管理员

## 一张网是什么

外部知识源（"知识一张网"）以**切片**形式批量接入平台。关键设计（47 号设计文档）：

- 切片**不是旁路证据**，也不单独建设一套检索——它进入现有解析和挖掘主链，**重建为可浏览、检索和引用的逻辑文档**；
- 同一份资料完成一次加工后，可被多个业务知识库**只读复用**（三层模型：管理员导入向导 → 域公共库产出一次 → 各库引用复用）；
- 上游内容变化通过**重同步**传播。

## 管理员页：导入向导

### 1. 查询产品文档

按**产品线**查询上游一张网的产品文档，得到章节树（大文档 5000+ 节点时默认只展开根层、层层点开）。

### 2. 选择还原模式（怎么把切片还原成文档）

| 模式 | 行为 |
|---|---|
| **按产品文档章节层级还原** | 沿上游章节树还原为逻辑文档 |
| **按路径中最近的文件后缀节点聚合** | 按路径中最接近文件的后缀节点聚合 |

若当前模式下全部切片找不到文件后缀锚点，页面会提示改用产品文档模式（部分切片找不到锚点的，将不会导入）。

### 3. 勾选导入范围

- 勾选章节（支持按章节名过滤，保留命中祖先链）；**不勾选任何节点 = 整包导入**；
- 勾选扩大时新文件会被拉到（三信号未变时短路返回的旧限制已解除）。

### 4. 提交导入

「导入任务已创建（后台拉取+挖掘，完成后在记录中查看）」——导入在后台拉取并挖掘，进度和结果看**导入记录**列表（含版本、范围、更新时间）。

### 重同步与"从记录继续"

- 上游内容有变更时，记录显示变更，可发起**重同步**；
- **从记录继续**：编辑已导入来源的勾选范围——已勾选 = 当前导入范围，新勾选章节将**合并并重同步**；
- 勾选范围已合并而上游无其他变化时，提示"勾选范围已合并；上游内容无其他变化"。

## 库侧：「一张网」tab

知识库详情的「一张网」tab 展示本库**引用**的一张网文档（引用 UNION 三类口径）：从域公共库引用来的逻辑文档在这里可见、可检索，与自建文档同链路消费。
