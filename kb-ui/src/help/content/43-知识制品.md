# 43 · 知识制品

页面：`/artifacts`（制品中心）、制品详情 ｜可见范围=我参与的 + 本域公开制品（站点管理员可见全部）

知识制品是**整理好、可发布、可供人和 Agent 使用的知识成果**。当前有两类：

| 类型 | 内容形态 | 典型来源 |
|---|---|---|
| **表格制品** | 结构化数据（行 × 列） | 上传 Excel |
| **Wiki 制品** | 页面正文 + 目录 + 页间链接 | 从知识库编译生成 |

两类制品共用同一套生命周期：**草稿 → 发布（rN 正式版）→ 停用 / 删除**，以及同一套权限与成员体系。修改先进草稿，**发布才对使用者生效**——正在使用正式版的人不受草稿影响。

制品详情固定四个页签：

| 页签 | 内容 | 谁可见 |
|---|---|---|
| **设计态** | 制表/编译、内容编辑 | owner / editor（viewer 默认落在运行态） |
| **运行态** | 正式版内容 + 说明卡 + Agent 引用 | 所有成员（含 viewer） |
| **成员** | 成员与角色管理（仅 owner 可操作） | 成员 |
| **版本** | 发布历史（rN）与回滚 | 成员 |

列表页支持按**类型 / 状态（草稿·已发布·已停用）/ 标题关键字**组合筛选。「新建制品」时选择类型、标题、描述与归属知识域，创建后直接进入详情页。

## 表格制品：从 Excel 到正式版

**① 导入 Excel（设计态 · 导入向导）**：选工作表 → 列映射 → 预览确认 → 导入草稿。列映射分两种模式：

| 模式 | 何时出现 | 规则 |
|---|---|---|
| 建表模式 | 制品还没有列 | 为每个文件列选择目标类型（文本/枚举/整数/浮点/日期/布尔），建议指定主键（可多列组合） |
| 追加模式 | 制品已有列 | **至少一列映射到已有列**；文件新列可新建；已有列而本批文件没有的，该批置空 |

**② 编辑**：列定义面板调整列（名称、类型、主键等）；数据编辑面板增删改行与单元格。编辑数据或改列都会自动检出草稿（页头出现「draft 开放中」）。

**③ 发布**：点「发布」先看**差异预览**（本次与当前正式版的差异），填写变更说明；**使用说明（usage_note）发布前必填**——它就是运行态说明卡给 Agent 看的用途描述。没有待发布变更时发布按钮置灰。

## Wiki 制品：从知识库生成

**① 来源绑定**：选择域与知识库，可限定目录（留空=全库）；无权限的库会标「库不可读」。来源知识库的知识资产更新后，面板会出现**「来源已变化，建议重新编译」**横幅。

**② 编译（状态机推进，可取消）**：开始编译 → 取材与聚类（大库可能需要数分钟）→ **目录确认**（编辑目录、勾选排除不需要的页）→ 逐页写作（显示批次与已写页数）→ 出报告（统计 / 冲突 / 错误）。

**③ 人工修订（人工页保护）**：编译生成的页面 `origin=machine`；人工新建或改过的页面 `origin=manual`（改 machine 页也会翻成 manual）。**重新编译只覆盖 machine 页；manual 页一律跳过并记入冲突报告**——人工修改不会在重编译时悄悄丢失。

**④ 目录**：设计态编辑器左栏可切到「目录」视图编辑分节目录并保存；运行态阅读器按该目录分节展示。

**⑤ 发布**：与表格同一发布对话框（计数单位=页）。发布前有确定性校验：页内 `[[src:]]` 引用悬空、机器页没有来源账会被**拦下**；人工页缺来源账只告警。

## 权限、可见性与生命周期

**角色（三类，两类制品同一套）**：

| 角色 | 能做什么 |
|---|---|
| **owner 拥有者** | 全部操作 + 成员管理 + 可见性修改 + 删除 |
| **editor 编辑者** | 编辑、发布、回滚；不能改成员与可见性 |
| **viewer 只读** | 只见运行态（设计态对其隐藏），不能编辑草稿 |

非成员访问制品得到 404（反探测，不泄露制品是否存在）。成员管理仅 owner：按登录名/显示名搜索本域用户，授予 viewer / editor / owner 角色。

**可见性（两档，仅 owner 可改——运行态「编辑元信息」）**：

| 档位 | 含义 |
|---|---|
| **私有**（默认） | 仅成员可见 |
| **本域公开** | 本知识域所有用户**可读**；**不等于互联网匿名公开**，编辑/发布/成员管理仍走成员角色 |

**停用与删除（两级）**：停用（deprecate）后制品对 Agent 侧不可见，可随时恢复；**删除必须先停用**，且仅 owner、需要**输入制品标题确认**——级联硬删全部行/列/版本/成员，不可恢复。

## Agent 消费：三个条件

制品要对 Agent（MCP 通道）可读，**三个条件缺一不可**：

1. **制品已正式发布**（草稿/未发布/已停用均不可见，rev0 从不开放）；
2. **钥匙主人本人可读**（是成员，或制品本域公开）；
3. **MCP 钥匙明确开放了本制品**——在 `/mcp`（第 15 章）对应钥匙的配置抽屉里，「开放的知识制品」勾选本制品。**不勾 = 制品通道对该钥匙关闭；公开也绝不会自动暴露给 Agent。**

运行态说明卡给出**引用键（artifact_ref，`art:` 开头）**，可一键复制交给 Agent；消费方式两类不同：

| 类型 | Agent 消费方式 |
|---|---|
| 表格制品 | 结构化查询（筛选列 / 聚合），运行态网页可直接浏览 |
| Wiki 制品 | 搜索页面 / 整页读取 / 链接导航，运行态网页可直接阅读 |

## 图谱视图与来源回查

Wiki 制品在设计态与运行态都有「**页面｜图谱**」切换：图谱是页面链接关系的只读图（断链虚线标出），点节点可直接打开对应页面（运行态图谱读正式版）。表格行与 Wiki 页均带**来源记账（provenance）**；Wiki 阅读器中页内引用切片可点开**原文截读弹层**（≤500 字定位预览），并可跳转到来源知识库查看。
