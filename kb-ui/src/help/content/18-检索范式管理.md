# 18 · 检索范式管理

页面：`/paradigm`（列表）、`/paradigm/:id`（编辑器）｜仅站点管理员

## 这是什么

检索范式是**可插拔检索算子 DAG**——决定一次检索走什么链路（召回 → 过滤 → 组装），"查询怎么找"（与挖掘范式相对，见第 17 章）。

关键规则：

- **范式跨域通用**，用哪个库检索由知识库自己**绑定**；
- 未绑定的库用**官方默认**（HTTP 调用方一般不用关心，见第 14 章 resolve 一步）；
- 有草稿 / 已发布 / 已归档三态和版本号；
- 检索时走的永远是**已发布**版本。

## 列表页

三态筛选 tab（全部 / 草稿 / 已发布 / 已归档），列：名称、描述、状态、当前版本（v{n}）、更新时间。操作：**编辑**、**归档**（已归档的可**删除**）。新建弹窗：唯一名称（如 `emb-only-baseline`）+ 描述。

## 编辑器（DAG 画布）

- **从左侧拖拽算子到画布**，从节点右侧「输出口」拖到下游左侧「输入口」连线；
- **不能成环**；部分算子有结构要求（如必须连 `scope_resolve`）；
- 节点有"单入 / 多入"方向约束与启用/禁用开关；
- 参数编辑：布尔、数组等控件；`kbIds` 类参数有库选择候选；
- **保存草稿** / **发布范式** / **版本历史**（历史版本可查看；该版本无图数据时只读降级）；
- 调试辅助：**复制 curl 调用示例**（直接得到一条对本范式的检索 curl）。

## 从模板开始

新建可选四个内置模板（`templates.ts`）：

| 模板 | 用途 |
|---|---|
| ① 关键词证据检索 | 纯关键词链路 |
| ② 标准混合证据检索（**官方默认**） | 关键词+语义混合，绝大多数库用这个 |
| ③ 纯向量评测（基线） | 评测用 |
| ④ 纯全文评测（基线） | 评测用 |
| 空白画布 | 从零编排 |

## 绑定关系速查

| 层 | 谁配 | 效果 |
|---|---|---|
| 官方默认 | 平台级 | 没有任何绑定时回落到这里（resolve 返回 `source: "official"`） |
| 库级绑定 | 知识库 | 该库检索走绑定范式（`source: "library"`） |
| 显式传参 | HTTP/MCP 调用方 | 一般不传；传错域的范式报 `paradigm_domain_mismatch` |

域级 resolve 没有可用范式时（`bound: false` / `no_paradigm_configured`）→ 到本页确认有**已发布**范式。
