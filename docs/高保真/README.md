本目录只包含交互评审材料，不是业务前端实现，也不连接真实数据库、文件上传或模型服务。

版本入口：**1.1.15 知识制品管理**使用 [artifacts-1115.html](artifacts-1115.html)；**1.1.16 制品工作区**使用 [workspace-1116.html](workspace-1116.html)。两份原型分别演示制品管理和制作过程，工作区不属于 1.1.15 开发范围。

- [artifacts-1115.fragment.html](artifacts-1115.fragment.html)：可编辑原型源文件，用于修改界面与本地交互。
- [1.1.15 开发需求说明书](../下一阶段/66-知识制品统一界面-1.1.15开发需求说明书-2026-10-28.md)：开发和验收的执行依据。
- [功能说明通俗版](../下一阶段/65-知识制品与制作工作台-功能说明通俗版-2026-10-28.md)、[技术参考](../下一阶段/64-知识制品管理与制品工作区-需求规格与现有实现对照-2026-10-28.md)：跨版本背景，工作区相关内容不属于 1.1.15。

浏览器不能直接预览 GitHub 的 HTML 原始页面时，请先下载文件。独立网页保留 sandbox iframe 和 CSP；不要为了调试删除这些边界。

导出壳包含固定版本的 CDN 图标／定位脚本，不代表新增应用依赖；断网时部分图标可能缺失。原型数据与主要操作在本地处理，不访问 AgenticKB 的真实服务。

## 建议走查

1. 从列表打开表格或 Wiki，查看统一的设计态、运行态、成员和版本。
2. 修改表格草稿，再切运行态核对正式内容未变化；体验 Excel 示例导入及发布。
3. 在 Wiki 设计态选择“从知识库生成”，确认目录后生成草稿，检查人工页面保护。
4. 在“页面编辑／阅读”和“图谱视图”之间切换。图谱节点是页面，箭头是引用；点击节点后可返回正文。
5. 在草稿正文增加 `[[不存在的页面]]`，保存后核对草稿图谱中的断链；发布前运行态旧图不变化。
6. 顶部示例用户选择器仅用于模拟角色，不能作为生产身份功能实现。

## 维护规则

以 `artifacts-1115.fragment.html` 为编辑源，完成交互检查后重新导出 `artifacts-1115.html`，两个文件和 66 号说明书同一次提交更新。不要只修改生成的独立网页，否则下一次导出会丢失修改。

本原型通过 visualize 技能的导出工具生成独立网页，等价命令为：

```text
python <visualize技能目录>/scripts/render.py docs/高保真/artifacts-1115.fragment.html docs/高保真/artifacts-1115.html --force
```

只有维护原型时才需要导出工具；查看已提交的独立网页不需要 Codex 环境。页面内容和示例状态均在浏览器中处理，不要把真实业务敏感数据输入原型。

## 1.1.16 制品工作区

- [workspace-1116.html](workspace-1116.html)：完整独立网页，浏览器直接打开。保留沙盒 iframe 和 CSP。
- [workspace-1116.fragment.html](workspace-1116.fragment.html)：可编辑的工作区原型源文件，与独立网页对应。

本版只包含制品工作区；知识制品的设计态、运行态、成员、版本和正式发布继续参考 1.1.15 原型。

建议依次体验：

1. 默认“电源产品规格整理”工作区：点“抽取产品信息”的两个输出口，查看产品规格表和配套关系表。
2. 点“关联产品库存”，切“输入”对照左右两张表；右侧修改关联方式，先试跑，再执行。修改上游后，下游旧结果会标记待更新。
3. 在“流程画布”和“内容视图”之间切换，保持当前节点和输出；“放大内容”进入专注查看。
4. 右侧“节点配置／加工助手／来源修正”均针对当前选中节点。点击单元格可修正数值并填写原因。
5. 切到“Wiki 示例”，在 Markdown 页面、页面清单和关系输出之间切换；关系支持列表与知识图谱，并可从图节点定位正文。
6. 查看运行记录与历史快照，体验“用新资料重跑”；人工正文和链接修正重跑后会保留，关系随最终正文重新计算。
7. 点击工作区名称可切换或新建空白工作区，接入示例来源，再从算子库添加加工节点。
8. 选择一个或多个结果“导出制品草稿”，确认名称和默认责任人。导出只创建私有草稿；本原型止于交付回执，不执行正式发布。

AI、SQL、导入和脚本转换均为本地模拟，不能作为真实服务已经实现的依据。示例交互状态可随宿主保存；不要输入业务敏感信息。

维护时修改 `workspace-1116.fragment.html`，检查交互后重新导出独立网页，并同步两个文件：

```text
python <visualize技能目录>/scripts/render.py docs/高保真/workspace-1116.fragment.html docs/高保真/workspace-1116.html --force
```

本版已走查多输入输出、试跑与执行、下游失效提示、Markdown 未保存保护、重跑后关系同步、状态恢复、草稿交付，以及桌面、窄屏和深色外观。以上属于原型验证，不代替 1.1.16 的真实服务验收。
