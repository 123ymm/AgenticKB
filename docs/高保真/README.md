浏览器不能直接预览 GitHub 的 HTML 原始页面时，请先下载文件。独立网页保留 sandbox iframe 和 CSP；不要为了调试删除这些边界。

导出壳包含固定版本的 CDN 图标／定位脚本，不代表新增应用依赖；断网时部分图标可能缺失。原型数据与主要操作在本地处理，不访问 AgenticKB 的真实服务。

## 建议走查

1. 从列表打开表格或 Wiki，查看统一的设计态、运行态、成员和版本。
2. 修改表格草稿，再切运行态核对正式内容未变化；体验 Excel 示例导入及发布。
3. 在 Wiki 设计态选择“从知识库生成”，确认目录后生成草稿，检查人工页面保护。
4. 在“页面编辑／阅读”和“图谱视图”之间切换。图谱节点是页面，箭头是引用；点击节点后可返回正文。
5. 在草稿正文增加 `[[不存在的页面]]`，保存后核对草稿图谱中的断链；发布前运行态旧图不变化。
6. 顶部示例用户选择器仅用于模拟角色，不能作为生产身份功能实现。

## 维护规则

以 `artifacts-1115.fragment.html` 为编辑源，完成交互检查后重新导出 `artifacts-1115.html`，两个文件和 66 号说明书同一次提交更新。不要只修改生成的独立网页，否则下一次导出会丢失修改。

本原型通过 visualize 技能的导出工具生成独立网页，等价命令为：

```text
python <visualize技能目录>/scripts/render.py docs/高保真/artifacts-1115.fragment.html docs/高保真/artifacts-1115.html --force
```

只有维护原型时才需要导出工具；查看已提交的独立网页不需要 Codex 环境。页面内容和示例状态均在浏览器中处理，不要把真实业务敏感数据输入原型。

## 前端开发边界

按照 66 号中的模块清单，在现有 Vue 组件和真实服务上实现。Wiki 图谱优先复用分支已有的页面／引用查询，新增展示组件，保持草稿与正式版本权限；不要把它扩建成 1.1.16 的制作流程画布。

本目录不包含真实 Excel 解析、真实知识库生成、跨服务权限和模型质量验收。原型交互通过不等同于 1.1.15 产品已开发完成。

## 原型交互检查

在已有 Playwright 环境中运行 `node docs/高保真/test-artifacts-1115.cjs`，可检查图谱切换、节点定位、别名去重、断链、草稿隔离、只读角色和窄屏布局。默认使用已安装的浏览器；需要指定浏览器时设置 `PROTOTYPE_BROWSER_PATH`，不要求修改业务前端的依赖文件。
