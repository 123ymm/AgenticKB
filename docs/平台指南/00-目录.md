# AgenticKB 平台指南 · 总目录

> 这是一本关于平台的完整说明书：使用者看用户篇，开发者看开发篇，运维看运维篇，各取所需。
> 全部内容严格从代码与项目文档中提炼，每章末尾附「本章素材来源」，可逐条核验。

## 本书规矩

1. **忠实**：每句话都能追溯到代码或已有文档，不凭空描述不存在的功能。
2. **现态优先**：书写"平台现在是什么样"；演进方向与未上线设计会明确标注，不与现状混写。
3. **可核验**：每章末尾列出素材来源（代码文件 / 文档）。
