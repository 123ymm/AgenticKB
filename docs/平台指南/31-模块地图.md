# 31 · 模块地图：每个服务干什么

面向开发者的代码导航图。按服务列出目录与职责，改代码前先在这里定位。

## knowledge_mining（:8901，Python/FastAPI）

平台的主体服务：KB 管理、文件、挖掘、生命周期、一张网接入。

| 目录 | 职责 |
|---|---|
| `mining/api` | HTTP 接口层之一（服务级路由 `routes/`：health/knowledge/ops/runs/workflows） |
| `mining/kb` | **KB 核心**：库/文档/成员/检索就绪度/一张网引用等路由（`kb/routes/`：kbs/documents/folders/mcp_keys/mcp_tools/mining/overview）与 DB 层（`db.py`、`services/`） |
| `mining/workflow` | **挖掘范式执行后端**：bundle/compiled_input/compiler/core——Run 按冻结 workflow 版本执行（进度阶段从冻结 workflow 推导，不再映射旧 12 阶段模型） |
| `mining/file_management` | 逻辑目录树、对象上传登记 |
| `mining/jobs` | 挖掘 Run 执行（`run.py` 按对象身份读输入） |
| `mining/stages` + `pipeline.py` | 流水线阶段与算子（解析/切片/篇章加工/入库等） |
| `mining/parse_adapters` / `parse_operator` / `parse_quality` / `parse_reconciler` / `shadow_parse` | 多格式解析适配、解析编排、质量门禁 |
| `mining/segment_compiler` / `retrieval_projection` / `table_assets` | 切片编译、检索投影（检索单元/向量）、表格资产事实 |
| `mining/snapshot` / `snapshot_store` | 快照生命周期与指纹存储（域级共享） |
| `mining/onenet` | 一张网切片接入（适配器、导入编排、重同步） |
| `mining/contracts` | Layer-1 契约：frozen dataclass + Protocol，零外部依赖 |
| `mining/frozen_input` | 冻结输入（stale 校验） |
| `mining/source_locator` | 来源定位（搜索到原文，A1） |
| `mining/infra` / `runtime` / `maintenance` / `ingestion` / `file_inspector` / `file_migration` | 基础设施、运行时、维护任务（含 database_upgrade 迁移工具）、摄入与文件检查/迁移 |

> 定位一个端点：先想它属于**服务级**（`mining/api/routes/`）还是 **KB 面**（`mining/kb/routes/`）。

## llm_service（:8900，Python/FastAPI）

LLM 运行时：异步任务通道（embedding/generation/caption）、重试与死信、模型调用审计、提示词模板。`providers/` 是模型提供方适配；有自己的 `pg_schema.py`（LLM 任务表链）。架构文档见 `llm_service/ARCHITECTURE.md`。

## main_control_service（:8910，Python）

主控配置中心，**必须最先启动**：

| 文件 | 职责 |
|---|---|
| `auth.py` / `jwt_util.py` / `internal_auth.py` | 登录认证、JWT 签发、服务间内部认证 |
| `proxy.py` | 域路由代理（`/api/control-plane/api/v1/proxy/{domain}/...` 的分发中枢） |
| `config.py` + `config/` | 系统配置唯一来源（system/*.yaml、domain_registry.yaml） |
| `restart_services.py` | 一键重启编排（依赖序重启后台服务，nginx 不动） |
| `release_info.py` | 版本信息（releases.json → 前端"新版本"弹窗） |
| `ip_whitelist.py` | IP 白名单 |

## agent_serving_java（:8081，Java/Spring Boot）

检索与结构读取服务，包结构 `com.coremasterkb.serving`（16 个包）：

| 包 | 职责 |
|---|---|
| `operator/api` + `operator/operators/` | **检索范式执行**：ParadigmController/ParadigmRunController（resolve/search 端点）与算子实现（含 scope 解析、输出组装） |
| `api` | 证据/结构 REST（EvidenceApiController、StructureApiController）、Admin、Health、全局异常（错误码族） |
| `structure` / `retrieval` / `rerank` | 结构读取（章节导航/表格）、检索核心、重排 |
| `domain` / `domainpack` | 领域模型（ActiveScope 白名单等）与域包（检索策略权威） |
| `evidence` | 证据读取与展开 |
| `entity` / `mapper` / `repository` | JPA 实体、MyBatis mapper、仓储（当前文档范围、Build 选择） |
| `infrastructure` / `config` / `observability` / `application` / `util` | 基础设施、配置、观测、应用装配、工具 |

改 Java / `application.yml` 必须**重新 build 镜像**（无 volume 挂载，见第 33/40 章）。

## mcp_server（:9000，Python/FastMCP）

外部 Agent 入口：`identity.py`（钥匙实时验证、单域校验）、`tools.py`（search_knowledge / get_knowledge / upload_document 三工具与开关）、`schemas.py`、`client.py`（调 serving/mining）。9000 端口全网绑定供直连。

## kb-ui（Vue 3 + Element Plus + Vite + Pinia）

| 目录 | 内容 |
|---|---|
| `src/views/` | 页面：kb/（列表/详情/文档预览/Run 详情）、mining/（Workflow）、paradigm/、onenet/、llm/、McpAccess、UserManagement、Settings、Dashboard、Login |
| `src/components/kb/` | 库详情各 tab 面板：FileManager/SearchPanel/MiningPanel/MembersPanel/QualityPanel/OnenetRefPanel/SettingsPanel、表格查询面板、结构图、PipelineFlow |
| `src/components/settings/` | 系统状态、服务重启卡片（site-admin）、用户管理与导入 |
| `src/components/layout/` | 侧栏（ALL_NAV 权限过滤）、Header |
| `src/api/` | proxyClient（统一走 control-plane 域路由代理）等 |

**前端类型验证必须 `npm run build`**（vue-tsc -b；`--noEmit` 在 references-only 根 tsconfig 下是空检查假通过——铁律见 superpowers 计划与 53 号文档）。
