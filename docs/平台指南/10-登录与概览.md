# 10 · 登录与概览

页面：`/login`（登录）、`/`（概览 Dashboard）｜所有人可用

## 登录

浏览器打开平台地址（内网部署形如 `http://<服务器IP>:8080`，端口以部署告知为准），输入账号密码登录。token 默认 12 小时有效，过期自动回到登录页。

- 账号按**三种角色**开通：站点管理员（全域通行）、域管理员（管理本域成员）、普通成员（按域与库授权），详见第 20 章；
- 忘记密码：找**站点管理员**在「用户管理」重置（域管理员不能改密码，见第 20 章）；
- 登录后可从右上角账户菜单**修改密码**。

侧边导航（`Sidebar.vue` 的 ALL_NAV）按权限过滤渲染：

> 独立"检索"菜单已下线——检索入口收进知识库详情的「检索」tab，全部走检索范式。

## 概览页：先看这一节——页面上同时存在三套口径

**相邻的两个数字很可能不是同一个范围里的东西**，看数前先确认口径：

| 口径 | 覆盖范围 | 出现在 |
|---|---|---|
| **A. 我可见的知识库** | 当前用户在本域能看到的全部知识库（管理员=全域） | 「知识库概况」与图表、知识库卡片 |
| **B. 全域检索流量** | 本域所有检索请求，不按知识库收敛 | 「运维概览」（仅管理员可见） |
| **C. 域级 active release** | 已发布语料的快照范围 | 系统状态页签内「知识资产」区块 |

要点：A 和 B 的数字没有可比性；**纯知识库部署下口径 C 恒为空**（知识库挖掘只构建不发布——见第 02 章「发布」词条）——那显示的是"口径不适用"，不是"知识丢了"。

### 知识库概况（口径 A）

顶部四个数字（DashboardView 的 tiles）。除「知识库」外，都只统计**当前知识**（每篇文档最近一次成功挖掘的快照）：

| 指标 | 含义 | 注意 |
|---|---|---|
| 知识库 | 你能看到的知识库数量 | 管理员见全域 |
| 文档 | 文档总数 | 取文档状态分布各档之和，不是各库相加 |
| 已挖掘 | 挖掘成功、已产出知识的文档数 | 与"文档"的差额=待挖+处理中+失败 |
| 检索单元 | 可被检索命中的最小知识单位 | 一篇文档切出多个，远大于文档数 |

> 为什么不对表求和：一篇文档每重挖一次产生一份新快照，只统计每篇**最近一次**进入 validated/published 构建的那份，否则挖过 3 遍的 10 篇会显示成 30 篇的知识量。

### 待处理

只在有内容时渲染，只列你有写权限的库：

| 待办 | 触发条件 | 动作 |
|---|---|---|
| 挖掘已暂停，等待人工审核 | 该库有 run 停在 `awaiting_review` | 点进 run 详情处理 |
| N 篇文档解析失败 | 该库有文档 `failed` | 点进知识库查看 |

待人审排在解析失败前：它卡住的是整条流水线。

### 运维概览（口径 B · 仅管理员）

窗口默认近 7 天，趋势折线固定 30 天：

- **检索次数**：掉到 0 通常意味着接入断了，不是"没人用"；
- **零结果率**：最有行动价值的指标，直接反映知识覆盖缺口；
- **P95 延迟**：95% 的请求比这个值快——平均值会被大量快请求稀释、把少数卡死的用户藏起来，所以用 P95；
- **答不上来的问题**：**整个区块最该看的一段**，按出现次数排序的真实无结果查询原文（前 5 条，系统状态页签给全部）——零结果率只告诉你"有缺口"，这份清单告诉你"缺口在哪"；
- 零结果告警需同时满足"检索 ≥ 20 次 且 零结果率 ≥ 20%"才出现（样本门槛是刻意的）。

### 图表与「我的知识库」

- **文档状态分布**（环形图）：最多七档——已入库 / 处理中 / 待挖掘 / 失败 / 更新失败 / 已发布 / 已撤回；域内无 active release 时"已发布/已撤回"两档整个摘掉（纯知识库部署显示五档），计数为 0 的档保留（"失败 0"本身是有用信息）；
- 近 30 天入库文档数（无挖掘日补 0，不跳过）、各知识库文档数（前 8）、检索单元类型分布；
- 每张库卡片右上角状态角标，优先级 **失败 ⚠ > 挖掘中 ⏳ > 就绪 ✓**（失败优先于挖掘中：失败需要人动手，挖掘中只需要等）；卡片上的角色徽标（拥有者/编辑者/只读/管理员）是**展示用途**，"管理员"徽标指你的站点/域管理员身份，不是库内角色；
- 「最近挖掘」：跨库最近 5 次挖掘记录，整行可点进 run 详情，含文档增量（`+N` 新增 / `~M` 更新）。
