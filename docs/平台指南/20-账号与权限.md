# 20 · 账号与权限

页面：`/users`（用户管理）、库详情 ·「成员」tab 与「设置」tab｜用户管理对域管理员及以上开放

## 权限模型（三层大白话）

```text
账号（你是谁）──> 所属域（你在哪个院子）──> 库内角色（你在院子里哪个库能干什么）
```

- 每个账号属于至少一个域（站点管理员例外，全域通行）；
- 知识库归属拥有者所在域；库内角色：**拥有者 / 编辑者 / 只读**（第 02 章词典）；
- MCP 钥匙：一人多把，一把钥匙绑定一个域（第 15 章）。

## 三种角色能干什么

| 角色 | 能力 | 关键边界 |
|---|---|---|
| **站点管理员** | 全域通行；见全部管理导航；**全局用户管理**：创建账号、编辑用户、重置密码、分配域权限、禁用/恢复/清退 | 不写域绑定表 |
| **域管理员** | 管理本域：**添加/移除普通成员、CSV/XLSX 批量导入本域成员、搜索候选用户、从本域移除**；域用户管理 | 只能管自己任管理员的域；只能加**普通成员**，不能授予域管理员/站点管理员、不能操作其他域；必须是密码账号；**不能修改密码**（用户忘记密码找站点管理员重置） |
| **普通成员** | 使用被授权的库；MCP 接入；检索 | 库内能做什么由库内角色决定 |

> 已知边界：检索侧授权没有管理员旁路——别人的私有库，站点管理员直接检索也是 404（见第 14 章错误码）。

## 用户管理页：两个视角

同一页面按身份呈现两种视角（`UserManagementView.vue`）：

| 视角 | 提示文案（页面原文） | 能做什么 |
|---|---|---|
| **全局用户管理**（站点管理员） | "你是系统管理员，可以创建和维护全局账号，并为用户分配不同知识域中的普通用户或域管理员权限" | 建全局账号、编辑用户（设初始密码/给无密码用户补密）、重置密码、分配域权限、禁用、恢复账号、清退 |
| **域用户管理**（域管理员） | "你是当前域的域管理员，可以添加或移除普通成员，并管理本域所有知识库；不能修改全局账号、密码或系统角色" | 增删本域成员、批量导入、候选搜索 |

### 账号生命周期操作（用户管理页）

| 操作 | 行为 |
|---|---|
| 创建/编辑用户 | 登录名不可改（身份键）；无密码用户需设至少 8 位密码；管理员密码至少 8 位 |
| 重置密码 | 站点管理员操作 |
| 禁用（disabled） | 可恢复暂停：保留域、库关系和 MCP 配置，但 Web/API/MCP 实时拒绝访问 |
| 恢复账号 | 从 disabled 恢复 |
| 清退（deleted） | 永久清退：权限、成员关系、MCP 全部清除；用户名保留不复用；清退确认框会显示影响面（域绑定数、库成员关系数、MCP 钥匙） |
| 从本域移除 | 该用户仍拥有本域知识库时后端会拒绝并提示——先转移库拥有者（见下） |
| CSV/XLSX 导入 | 批量导入普通账号 / 批量添加本域成员（两套模板，导入弹窗内取） |

## 库成员管理（「成员」tab）

库详情「成员」tab：**拥有者或编辑者**可添加/移除成员、授予库内角色。候选用户来自本域。公开库全员可读无需加只读成员——此处仅可授予「编辑者」写权限。

## 库拥有者转移（「设置」tab）

库详情「设置」tab → **「转移所有者」**：搜索候选用户并转移（第 11 章）。这是"从本域移除被库挡住"时的正解。

## 给脚本/集成的建议

为自动化脚本**专建服务账号**，把它加进需要的库里（成员即可，只读用途），配合"一 Agent 一钥匙 + 最小开放库"（第 15 章）——检索日志不记录发起人（第 14 章），账号边界就是审计边界。
