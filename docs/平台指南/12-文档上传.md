# 12 · 文档上传

页面：库详情 ·「文件」tab、文档预览页｜需要拥有者或编辑者权限

「文件」tab 是知识库的文件管理器：目录树 + 文件列表，也是**挖掘触发的统一入口**（多选文件后批量操作；「挖掘」tab 只展示任务，见第 13 章）。

## 支持什么

- **格式**：Markdown、文本、HTML、PDF、Word（.docx）等；
- **归档包**：zip / hdx / chm 归档（与网页端一致，上限 500MB）会**自动解压成多个文档**，解压出的文档在「压缩包名/」目录下；大量小文件打包一个 zip 上传更高效；
- **普通文件上限**：50MB；
- 大归档在后台解压入库（"较大，正在后台解压入库…"提示，最长约 30 分钟），解压完成后文件列表可见，**解压耗时较长，可稍后刷新查看结果**。

> 归档解压在后台跑：期间解除上传锁，轮询完成后自动刷新树。

## 基本操作

| 操作 | 怎么做 |
|---|---|
| 上传 | 「上传到当前文件夹」，或拖拽文件进列表 |
| 新建文件夹 | 「新建文件夹」按钮 |
| 进入/改名 | **单击进入，双击改名**（计时器区分）；文件夹同理 |
| 移动 | 拖拽文件/文件夹到目标文件夹；拖到空白处 = 移到根目录 |
| 右键菜单 | 停在列表内右键：更多操作（下载、替换、删除等） |
| 替换 | 「替换当前文件」——换内容不换位置 |
| 下载 | 「下载最新原文件」 |
| 多选 | 勾选文件/文件夹（勾选文件夹 = 递归选中其下文档）；表头全选 = 当前页（服务端分页，默认 50/页） |

## 批量操作（多选后出现批量栏）

- **挖掘选中**：对选中文档发起挖掘（发起前需已绑定挖掘范式，否则提示"请先在「挖掘」tab 选择挖掘范式"）；
- **强制重挖选中**：忽略内容哈希缓存，对选中文档重跑完整 pipeline（含 LLM 阶段），重生已挖知识；
- **删除选中** / **批量永久删除**：走统一硬删管线批量端点——**永久删除文件及其全部挖掘内容，不可恢复**，有计数确认。

## 删除的语义

- 文件删除是**硬删**：连带其全部挖掘内容，确认弹窗会给出精确计数（"将永久删除文件…及其全部挖掘内容，不可恢复"）；
- 文件夹删除是**级联硬删**：先取预览计数（子文件夹+树下文档，含挖掘内容），该文件夹树下文档清零才删壳，绝不顺带多删。

## 文件列表的列与状态

名称（含状态）、类型、大小、修改时间。状态值（`docStatusLabel`）：

| 状态 | 含义 |
|---|---|
| 已入库 | 挖掘成功，知识可检索 |
| 已入库（未变化） | 最近一次增量判定 SKIP（内容没变，复用旧知识） |
| 未挖掘 | 已上传，尚未挖掘 |
| 处理中 | 正在挖掘 |
| 更新失败 | 更新失败，仍用上一版本（旧知识仍可检索，严重度低于彻底失败） |
| 挖掘失败，等待重试 | 需要人工关注 |
| 已发布 / 已撤回 | 仅域内有发布语料时出现（纯知识库部署不出现） |

另有附加标记**「待更新（旧知识可用）」**：文件换了、旧知识还在服务，直到重新挖掘。

## 文档预览页

点击文件进入 `/kb/:kbId/doc/:docId` 预览页：

- **版本横幅**：当前可搜索版本 ↔ 最新上传版本切换（两者不一致时明确提示"此处预览和下载的是最新原文件，可能与当前可搜索知识不同"）；
- **大纲导航**：按章节树导航，支持**本节搜索 / 本节及子节搜索**（跳转到库检索 tab 并锁定范围）；
- **结构内容**：章节、表格、切片、元素证据按需展开；命中表格可**表格精确查询**（第 14 章 MCP 同款能力的网页入口）；
- **原件下载**：大文件预览直连（预签名 URL）；
- 注意：当前可搜索版本没有原始证据表示时（可能挖掘未完成或未生成检索表示），预览会提示而非显示空白。

## 上传后发生了什么

上传只是入库文件；要可检索必须**挖掘**：

```text
上传（文件就位，状态=未挖掘）
  → 绑定挖掘范式（挖掘 tab，见第 13 章）
  → 发起挖掘（文件 tab「挖掘选中」或挖掘 tab「整库挖掘」）
  → 挖掘产出快照 → 就绪度逐档上升（见第 02 章）
```

Agent 也可以通过 MCP `upload_document` 上传（自动排队挖掘），行为与网页端同源——见第 15 章。
